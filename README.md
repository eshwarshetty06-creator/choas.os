# CHAOS.OS

**A Chaos-Driven Operating System Interface.**

React + TypeScript + Vite + Tailwind + Framer Motion.

## Features

-   **CHAOS_CORE**: Deterministic state engine with Time Travel (Undo/Redo).
-   **Anti-Gravity Windows**: Physics-based window management that reacts to system entropy.
-   **Natural Language Terminal**: Regex-based intent parsing.
-   **Fate Events**: Choreographed, cinematic system events triggered by chaos thresholds.
-   **Knowledge Graph**: Auto-extraction of facts from user notes.

## Installation

```bash
npm install
```

## Running

```bash
npm run dev
```

## Testing

```bash
# Unit Tests
npm test

# E2E Tests (Headless)
npx playwright install
npx playwright test
```
