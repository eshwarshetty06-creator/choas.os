# CHAOS.OS v4.0

> **A Sentient Web Operating System exploring the boundary between order and entropy.**

CHAOS.OS is not just a dashboard; it is a living, reactive interface that evolves based on your interactions. Built with **React** and **TypeScript**, it simulates a futuristic operating system where "System Chaos" determines the stability, visuals, and behavior of your applications.

![Chaos OS Desktop Preview](https://via.placeholder.com/800x400?text=CHAOS.OS+Preview)

## 🌌 The Core Concept: Entropy
The system tracks a global **Chaos Level** (0% - 100%).
-   **Low Chaos:** The system is stable, clean, and responsive.
-   **High Chaos:** Glitches appear, files rot, audio distorts, and rogue processes spawn.
-   **You are the Architect:** Your actions (killing tasks, organizing files, calming the AI) reduce chaos. Neglect increases it.

---

## 🧩 Unique Applications
Unlike standard OS tools, every app in CHAOS.OS has a unique, gamified twist:

### 1. 💀 Task Killer (System Monitor)
*   **The Twist:** A gamified process manager.
*   **Gameplay:** "Malware" processes spawn randomly and increase system chaos. You must hunt them down and "kill" them to restore system stability and earn Bounty Score.
*   **Visuals:** Threat-level color coding (Red for malware, Indigo for system).

### 2. 📻 Signal Tuner (Radio)
*   **The Twist:** An audio player that decays.
*   **Gameplay:** Plays Lo-Fi beats for focus. As system chaos rises, the signal gets jammed with static noise and frequency drift.
*   **Visuals:** Minimalist "Braun-style" physical interface with reactive visualizations.

### 3. 📸 Glitch Studio
*   **The Twist:** Visual destruction suite.
*   **Function:** Upload normal images and use the system's corruption algorithms to "datamosh" them. Save the glitch art back to your real machine.
*   **Visuals:** Professional creative tool interface.

### 4. 🕳️ The Void (File Explorer)
*   **The Twist:** Ephemeral storage.
*   **Gameplay:** Files stored here are not safe. They slowly lose "Integrity" over time until they permanently delete themselves.
*   **Visuals:** Visualizes file health as a decaying health bar.

### 5. 🔮 Persona Mirror
*   **The Twist:** Psychological profiler.
*   **Function:** Analyzes your interaction patterns (aggression vs. curiosity) and builds a visual ID card of your "Shadow Self."
*   **Visuals:** Clean, ID-card style biometric display.

### 6. 🧠 Terminal
*   **The Twist:** Direct neural link.
*   **Function:** Chat directly with the Core AI (Gemini powered). Execute system overrides and uncover hidden lore.

## 🛠️ Technical Stack

*   **Framework:** [React 18](https://reactjs.org/) (Vite)
*   **Language:** [TypeScript](https://www.typescriptlang.org/)
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/) (Custom Design System)
*   **State:** [Zustand](https://github.com/pmndrs/zustand) (Reactive Chaos Store)
*   **Animations:** [Framer Motion](https://www.framer.com/motion/)
*   **Audio:** [Howler.js](https://howlerjs.com/)
*   **AI:** Gemini 2.5 Flash Integration

## 🚀 Getting Started

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/eshwarshetty06-creator/choas.os.git
    cd chaos.os
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run logic:**
    ```bash
    npm run dev
    ```
